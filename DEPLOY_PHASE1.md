# GitHub Pages deployment

1. Push/upload the contents of this folder to the root of the `bookloks` GitHub repository.
2. In GitHub: Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`; folder: `/ (root)`.
5. Save.
6. GitHub will provide the Pages URL.

The app uses relative paths, so a project URL such as `https://bookloxindia.github.io/bookloks/` is supported.
